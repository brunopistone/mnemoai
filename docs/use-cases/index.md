# Use cases

Start with a task you recognize. These workflows combine MnemoAI's conversation,
tools, and configuration features.

<div class="grid cards" markdown>

- **Fix and verify code**

    Investigate a failure, make a focused change, and inspect the result.

    [Work on code →](code.md)

- **Research and write with documents**

    Gather evidence from files or indexed documents and produce a grounded draft.

    [Work with documents →](documents.md)

- **Manage ongoing work**

    Steer a running task, queue the next one, and resume the project later.

    [Keep work moving →](ongoing-work.md)

</div>
