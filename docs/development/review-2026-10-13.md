Initial combined testing exposed outdated fixture contracts and an overly broad
non-Git review coverage notice; these were corrected with explicit regressions.
Release CI also exposed Anthropic's move from `httpx` to `httpx2`. Token refresh
now uses the SDK-owned transport type with origin-bound request hooks, and the
transport tests mock both families with a real-network guard. The focused
117-test provider suite passed on both SDK stacks.
The live tier uses temporary app data and a neutral working directory, not the
user's conversations or memory. Other providers' constructor/transport checks
are simulations, not claims of live SageMaker/OpenAI/Anthropic deployment tests.
No zero-bug guarantee is implied.

The OpenAI Python SDK's documented retry defaults and `max_retries=0` behavior
were checked against the installed SDK and the
[official Python reference](https://developers.openai.com/api/reference/python/#retries).
