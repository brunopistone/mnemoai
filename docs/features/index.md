# Features

Work with files and tools, keep a conversation going, and direct the assistant
while it works. Start with a workflow, then explore the capabilities it uses.

[Try a workflow](../use-cases/index.md){ .md-button .md-button--primary }

## Workflows

<div class="grid cards" markdown>

- **Sessions and history**

    Resume, name, branch, or rewind a conversation.

    [Manage sessions →](sessions.md)

- **Queue, steer, and cancel**

    Send guidance to the current task or save a separate task for later.

    [Control pending work →](queue.md)

- **Long-running work**

    Continue through execution checkpoints and conversation compaction.

    [Understand continuation →](long-running-work.md)

- **Sub-agents and orchestration**

    Delegate useful independent work and receive the results in the main conversation.

    [Understand delegation →](../guides/orchestration.md)

- **Peer review**

    Ask an optional reviewer to assess work and return evidence-based feedback.

    [Use peer review →](../guides/peer-review.md)

</div>
