# Releases and project links

- [GitHub releases](https://github.com/brunopistone/mnemoai/releases) — published
  versions, release notes, and downloadable artifacts.
- [Changelog](https://github.com/brunopistone/mnemoai/blob/main/CHANGELOG.md) —
  changes by version. The **Unreleased** section describes work not yet included
  in a release.
- [PyPI package](https://pypi.org/project/mnemoai-assistant/) — Python package
  versions and installation metadata.
- [Source repository](https://github.com/brunopistone/mnemoai) — code and project history.
- [Issue tracker](https://github.com/brunopistone/mnemoai/issues) — report a
  reproducible problem or suggest an improvement.
- [License](https://github.com/brunopistone/mnemoai/blob/main/LICENSE) — MIT license.

## Updating

Use the update instructions for your installation method in
[Installation](../getting-started/installation.md#2-install-mnemo-ai).

## Reporting a problem

Include the installed version, operating system, selected provider and model,
the action you took, and what happened. Use
[Check your installation](diagnostics.md) and
[Troubleshooting](../development/troubleshooting.md) to find relevant diagnostics.
Remove credentials and unrelated private content before sharing logs or transcripts.

Contributors can find the [release checklist](../development/releases.md#release-checklist)
in the developer documentation.
