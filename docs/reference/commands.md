# Commands { #commands }

| Command                    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/help`                    | Show the command reference and keyboard keys. The launch banner deliberately doesn't print it — this is where the full list lives, and `/` searches it as you type                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `/exit` or `/quit`         | Exit the application                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `/clear`                   | Clear conversation history and RAG index                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `/rewind`                  | **Take back your last prompt** and everything the turn produced, from the conversation and the transcript. Moves the conversation only — **files on disk are untouched** ([details](../features/sessions.md#taking-back-your-last-prompt))                                                                                                                                                                                                                                                                                                                                                                 |
| `/context`                 | Break down **what is filling the context window** right now — system prompt, steering files, tool schemas, conversation — with each part's share and how much room is left ([details](../features/context.md#seeing-where-the-context-goes))                                                                                                                                                                                                                                                                                                                                                              |
| `/save`                    | Save the current conversation. After a `/load` (or an earlier `/save`), a bare `/save` **overwrites that same file**; `/save <path>` saves to a specific file/dir; a fresh conversation (after `/clear`) saves to a new timestamped file                                                                                                                                                                                                                                                                                                                                            |
| `/load <path>`             | Load a saved conversation (no path → pick from a list; the picker has a **Delete** button to remove a saved conversation after a Yes/No confirm, then reopens). The loaded file becomes the one a later `/save` writes back to                                                                                                                                                                                                                                                                                                                                                      |
| `/usage`                   | Token totals for this session, per model — input, output and cache tokens, counting **every** model call including sub-agents, orchestrator workers and the query router. Cumulative spend, not the size of your conversation ([details](../features/context.md#checking-token-usage))                                                                                                                                                                                                                                                                                                                    |
| `/files`                   | **What this session touched** — every file it read, wrote or you attached with `@`, newest first, with how many times each came up. Includes sub-agent and parallel-wave work, and survives compaction ([details](../features/changes.md#what-this-session-touched))                                                                                                                                                                                                                                                                                                                                      |
| `/diff [path]`             | **Uncommitted changes, with this session's edits marked `✎`** — staged, unstaged and untracked in one list with `+`/`−` counts. `/diff <path>` shows one file's colored diff. Read-only: it never stages, stashes or checks anything out ([details](../features/changes.md#seeing-what-changed))                                                                                                                                                                                                                                                                                                          |
| `/why [path]`              | **Which prompt asked for this change** — per change to a file: the turn, the request behind it, and what the call did, grouped by session. A bare `/why` lists every file with a recorded change. Answered from a small per-project index, so it costs no turn and reaches back past sessions that have expired ([details](../features/changes.md#why-a-file-looks-like-this))                                                                                                                                                                                                                            |
| `/copy [code\|N]`          | **Copy the last answer to the clipboard** without the terminal's line wrapping. `/copy code` takes its last fenced code block, `/copy 2` the answer before last. Uses a local helper or OSC 52, so it works over SSH too ([details](../features/sharing.md#copying-an-answer))                                                                                                                                                                                                                                                                                                                            |
| `/export [md\|txt] [path]` | Write the conversation as a **shareable transcript** — readable Markdown (default) or plain text — into the **current directory** unless you give a path. Not the same as `/save`: an export is a one-way artifact for pasting into a bug report or PR, not something `/load` can read back. Tool _calls_ appear as one-line summaries; tool _results_ and injected context are left out. Add `reasoning` to include thinking blocks ([details](../features/sharing.md#exporting-a-transcript))                                                                                                           |
| `/branch [turn]`           | **Fork this session** and carry on in the copy. No argument → pick the turn to branch after; `/branch 3` branches directly. The original session is **never modified** — it stays resumable with `--resume` ([details](../features/sessions.md#branching-a-session))                                                                                                                                                                                                                                                                                                                                       |
| `/rename [title]`          | **Name this session** so it's recognizable in the `--resume` picker instead of being labelled by its first prompt. No argument shows the current name; `/rename clear` removes it ([details](../features/sessions.md#naming-a-session))                                                                                                                                                                                                                                                                                                                                                                    |
| `/doctor`                  | **Check this install for problems** — config, provider credentials, required binaries, MCP servers, enabled features and their dependencies, and the files that grow. Local and read-only ([details](../resources/diagnostics.md#checking-your-install))                                                                                                                                                                                                                                                                                                                                                       |
| `/hooks`                   | List the **tool hooks** this session runs — your own commands fired before or after each tool call, from `~/.mnemoai/hooks/hooks.json`. See [Tool hooks](../guides/hooks.md)                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `/compact [focus]`         | Summarize older turns to shrink context (optional focus instructions)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `/config`                  | Re-run the interactive configurator — chat, vision (with a "same as chat?" shortcut + provider choice), and embeddings models, then feature toggles, then a model for each enabled internal call (router, orchestrator). `Ctrl+B` steps back within a model section. Overwrites `config.yaml` and restarts in place                                                                                                                                                                                                                                                                 |
| `/model`                   | Set up one model — chat (LLM), vision, embeddings, or one of the internal calls (router, orchestrator, summary — see [per-area models](../configuration/area-models.md#per-area-models-area_models)). Vision and the internal calls offer a "use the same model as Chat?" shortcut. Inference params reset to model defaults on a change (re-tune with `/params`). Chat, vision and embeddings restart in place; an internal call is **applied without restarting**, so the current conversation continues (unless the same edit switches routing or orchestration on, which needs the restart) |
| `/params`                  | Tune a model's inference parameters (temperature, top_p, top_k, penalties, reasoning, stop, stream, …) — only the params the chosen provider supports are offered. Applied **without restarting**, so the current conversation continues                                                                                                                                                                                                                                                                                                                                            |
| `/features`                | Enable/disable app features — a checklist of RAG, episodic memory, playbook, web search/crawl, routing, orchestration, memory, skills. Turning one on prompts for anything it needs (Brave API key, embeddings model); restarts in place                                                                                                                                                                                                                                                                                                                                            |
| `/mcp`                     | List the configured MCP servers (built-in + any from `mcp.json`), their connection status, and tool counts                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `/skills`                  | List installed skills (name + description); `/skills <name>` previews a skill's full instructions. See [Agent Skills](../guides/agent-skills.md) below                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `/memory`                  | View the curated persistent memory (`MEMORY.md`); `/memory clear` wipes it (with a y/N confirm)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `/auto [tier]`             | **Skip the confirmation prompt** for a tier of operations, this session only — `off` → `edits` (writes inside the working directory) → `writes` (any path, plus memory) → `all` (also shell). Bare `/auto` steps to the next tier; the input prompt carries a colored badge while one is active. Launch with `mnemoai --auto` to start at the top tier. The safety floor, plan mode, hook denials and git safety overrides are unaffected ([details](../guides/safety.md#stop-being-asked-for-a-while))                                                                                       |
| `/plan`                    | Toggle **plan mode** — an enforced read-only mode. While ON, the agent investigates and, when ready, presents a plan you **approve (y), edit in `$EDITOR` (e), or keep refining (n)**; approving turns plan mode off and the agent executes the plan in the same turn (saved to `plans/plan_<ts>.md`). Read-only shell commands (`ls`, `cat`, `grep`, `git status/log/diff`, …) still run; file edits, mutating shell, git writes, and background tasks are **hard-blocked** while ON. See [plan mode](../guides/safety.md#investigate-before-changing-anything) for full details             |

Beyond these, any `*.md` file you drop in `~/.mnemoai/commands/` becomes a command
you can type — see [Your own slash commands](../configuration/slash-commands.md#your-own-slash-commands).
